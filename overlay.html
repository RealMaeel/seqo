Point at a Dropbox / Google Drive / OneDrive folder to sync databases between computers. SEQO restarts after changing. One computer at a time.
Mirror loadout/UI files through the shared folder — newest wins, .seqo.bak backup kept. Camp before switching computers.
Which file do I sync for each game option?
Most of these live in your EverQuest Legends folder (next to eqgame.exe); loadouts are in its userdata subfolder:
• Spell loadouts — userdata\LF_Maeel_neriak.ini
• Character options, blocked spells, hotbuttons — Maeel_neriak.ini
• Advanced loot / autosell — most likely also Maeel_neriak.ini (unconfirmed). To find it for sure: change one autosell setting in game, camp, then sort the game folder by date modified — the file that just changed is the one to sync.
• UI window layout — UI_Maeel_neriak.ini
• Custom UI skin — use Add folder… on uifiles\<skinname> to mirror the whole skin
• eqclient.ini — ⚠ avoid syncing between different computers: it holds per-machine video/hardware settings.
